# 验证记录

## 1.1.0

- 默认配置只保留普通村庄、修道院和鲍勃酒馆；造炬成阳专用兼容层与对应默认条目已移除。
- 所有条目统一使用原版 `minecraft_structure` 定位器，从世界出生点查找结构并进入统一的安全落点搜索。
- 定位、外围区块加载和安全落点搜索状态显示在保持打开的选择界面中。
- 服务器就绪后先发送遮罩准备包，再发送选项包；准备界面从打开起就暂停，定位和加载期间继续显示，传送完成后才关闭。
- 增加实例根目录 `config/spawnselector.json` 统一覆盖文件：可禁用、覆盖、追加选项并修改分页布局；缺少的字段继承默认值。
- 选择界面在确认前使用 `isPauseScreen=true`，单人世界匹配 Origins 起源之球暂停；确认后界面保持显示以便服务端继续定位和加载，服务器侧仍保留伤害和移动保护。
- 出生选项名称和描述改用可着色的原版 JSON 文本组件；新增数据包界面配置，包括每页数量、尺寸、图标、预览图和全部按钮文字。
- 移除暂时关闭按钮、`cancel` 命令和五分钟自动暂停；断线、死亡及外部传送均不留下以后可消费的传送机会。
- 重新通过构建、10,000 组外围几何测试、1,839 处运行时链接检查、统一配置文件和资源检查；Forge Mods 配置屏幕和内置默认配置已打包进成品。
- 配置屏幕改为固定行高的左右两栏布局，条目列表、输入框、状态按钮和底部操作按钮分离，避免控件与文字重叠。
- 选择界面和 Origins 一样使用 `options_background.png` 纹理背景；首次等待和定位加载期间保持界面打开，传送完成后才关闭。
- Origins 关闭与 SpawnSelector 打开之间的渲染空窗由同一纹理背景覆盖，不会露出世界画面。
- 登录时提前发送遮罩武装状态；遮罩改在整个 HUD 渲染完成后覆盖，安全地面搜索按优先方位、9 点采样和区块复用执行，区块预算为 32。

## 1.0.1

- 根据实际 `latest.log` 定位到界面每帧解析空预览 ID，产生 `Invalid path minecraft:`；现在仅在非空预览 ID 下解析和加载材质。
- 界面与命令术语改为“永久跳过／暂时关闭”，新增仅权限等级 2 可执行的 `/spawnselector reset`。
- 重新通过构建、10,000 组外围几何测试、1,157 处运行时链接检查、资源和结构 ID 检查。
